# Dự án: Web Học Từ Vựng Tiếng Anh

## Công nghệ
- Backend: Django 4.x + Django REST Framework
- Frontend: React 18 + Vite + Redux Toolkit
- Database: PostgreSQL 14
- Cache: Redis
- Auth: JWT (djangorestframework-simplejwt)

## Giao diện
- UI Library: Material UI (MUI v5)
- Phong cách: xem file DESIGN-starbucks.md để làm theo
- Font: Inter hoặc Nunito
- Responsive: Desktop trước, mobile sau

## Quy tắc code
- Backend: PEP8, docstring tiếng Việt
- Frontend: ESLint, component dùng arrow function
- Tên biến/hàm: tiếng Anh, camelCase
- Comment: tiếng Việt

## Cấu trúc thư mục
- /backend  → Django project
- /frontend → React project
- /docs     → tài liệu

## Database
- Xem file TaiLieu_HocTuVung.docx phần mô hình dữ liệu
- Dùng Django migrations, không sửa DB tay
